One original dad joke, written to be told out loud: a father tells his daughter the washing machine is the hardest worker in the house — it does all the dirty work, never complains, and still gets taken for granted every single load. `main.py` (Python 3, standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (164 characters, no trailing newline).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
